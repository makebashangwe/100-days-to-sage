# 100 Days to Sage

Start Date: September 7, 2026
End Date: December 15, 2026

## Purpose

100 Days to Sage is a daily engineering gauntlet focused on developing
the practical software, systems, AI, infrastructure, electronics, and
problem-solving skills required to become an Intelligent Systems Engineer.

## Rules

- Build or study something every day.
- Produce evidence of work.
- Prefer implementation over passive consumption.
- Document failures and lessons.
- Small work counts.
- Missing perfection is acceptable; disappearing is not.
